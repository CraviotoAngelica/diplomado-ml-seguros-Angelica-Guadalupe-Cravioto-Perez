
# Tablero de cartera de seguros

Aplicación desarrollada con Streamlit para analizar una cartera de seguros de autos, visualizar indicadores de siniestralidad y cotizar primas con modelos estadísticos.

## Cómo ejecutar localmente

Instalar las dependencias:

pip install -r requirements.txt

Ejecutar el tablero:

streamlit run app_streamlit.py
